# Hipfire Crosshairs

Gives the snipers (Kraber, Longbow-DMR, DoubleTake) the Wingman Elite crosshair when unscoped, so hipfire has a usable crosshair instead of nothing. Client-side keyvalues patch.

## Features

- Wingman Elite crosshair (`ui/crosshair_wingman_n`) on the Kraber, Longbow-DMR, and DoubleTake when **not** ADS/scoped
- Scoped behaviour is untouched — only the hipfire (unscoped) crosshair is added
- Pure client-side keyvalues patch — works on vanilla servers, no scripts

## Install

Thunderstore-layout package — install via the Thunderstore mod manager, or drop the folder into `<profile>/packages/` so it becomes `packages/FromWau-HipfireCrosshairs-1.0.0/mods/FromWau.HipfireCrosshairs/`. Restart the game (keyvalues compile at startup).
